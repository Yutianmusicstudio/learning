# 本地环境（MacBook Pro M4 Max, 64G）

```bash
brew install git uv
git clone https://github.com/yutianmusicstudio/learning.git && cd learning
git checkout claude/gifted-ptolemy-wvzmcd
uv venv --python 3.12
source .venv/bin/activate
uv pip install torch numpy matplotlib jupyter
python code/00_check_env.py
```

每次打开新终端，先 `cd ~/learning && source .venv/bin/activate`。

- Mac 的 GPU 在 PyTorch 里叫 **MPS**，用 `torch.device("mps")`
- 64G 统一内存足够本地微调 7B 级模型（阶段 5），不需要租云 GPU
- 编辑器推荐 VS Code（`brew install --cask visual-studio-code`）或 Cursor
