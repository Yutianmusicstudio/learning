# 插播课：调参到底在调什么

## 一句话

**"调参"几乎总是指调"超参数"，不是调"参数"。**

| | 参数 | 超参数 |
|---|---|---|
| 是什么 | 模型自己学出来的数 | 人在训练前定好的设置 |
| 房价例子 | w | 学习率 η、训练多少步 |
| 谁来调 | 梯度下降（自动） | 你（手动做实验） |
| 数量 | 几个到几千亿个（Qwen-7B = 约 70 亿个） | 通常几个到几十个 |

## 常见超参数

- 训练模型：学习率、训练轮数（epochs）、batch size、网络层数和宽度
- AI 应用（以后工作里最常调的）：temperature、RAG 的 chunk_size 和 top_k、LoRA 的 rank

## 怎么调

1. 从公认的默认值开始
2. 一次只改一个，或者用网格搜索/随机搜索
3. 看 loss 曲线
4. **在验证集上比较，绝不在测试集上挑**（第 6 阶段细讲）

## "深度学习说到底就是调参"？

一半对：超参数没有公式能算出来，只能靠实验。
一半错：数据质量通常比调参重要得多；常见任务的默认值已经很成熟。
对 AI 应用工程师来说，"会调参" = **有章法地做实验 + 用评测数字证明哪个更好**。这就是 evals。
