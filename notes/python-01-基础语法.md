# Python 第 1 课：变量、类型、列表、字典、循环、判断

- 类型：int / float / str / bool / None
- f-string：`f"误差 {err:.2f}"`
- 列表：下标从 0 开始，`[-1]` 是最后一个，`[1:3]` 切片不含 3
- 字典：`d["key"]`，用名字找值
- 循环：`for x in xs`、`zip(a, b)`、`enumerate(xs)`、`range(n)`
- 缩进（4 空格）表示代码块归属
