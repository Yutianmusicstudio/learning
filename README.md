# 机器学习 → AI 应用工程师 学习计划

> 背景：美国音乐科技硕士（未接触音频/DSP），数学偏弱，会一些 Python
> 目标：国内通用 AI 应用工程师岗位
> 节奏：时间不限，9–12 个月做扎实

## 定位

- **主赛道（100%）**：通用 AI 应用工程师（RAG / Agent / 评测 / 微调 / 部署）—— 岗位大盘在这里
- **音乐方向**：只是可选的项目题材，不是策略。查证过：音乐 AI 岗位少且多为算法岗/标注合同工，"人才稀缺"无数据支撑
- **核心原则**：不跟 AI 比写代码，而是成为"能让 AI 系统在真实业务里稳定跑起来、并且能证明它好用"的人

## 规则

1. 每个项目必须有：README（问题/方案/取舍）+ **评测数字** + 失败案例
2. AI 编程工具从第一天就用，但**每一行代码都要能解释**
3. 数学只学直觉，遇到哪里讲哪里；PyTorch 负责算导数
4. 模型以国产 API 为主（Qwen / DeepSeek / 豆包），顺带熟悉 Dify / Coze
